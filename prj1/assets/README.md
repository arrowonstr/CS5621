# Water normal map

`waternormals.jpg` comes from the official Three.js r180 example assets, matching the project's `three@0.180.0` dependency.

Source: https://github.com/mrdoob/three.js/blob/r180/examples/textures/waternormals.jpg

The file is stored locally so the running project does not need an external texture server. It describes surface normals, not the visible color of the lake, and uses `NoColorSpace`.
